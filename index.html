Getting started

  1. Scan your first receipt. Tap the camera button in the bottom bar. Point at a paper receipt — the app crops, OCRs the text, and extracts amount, merchant, date, and line items on-device using Apple's Vision framework.
  2. Set up budget rules. In the Plan tab, add monthly income and fixed-expense rules. The app uses these to project your cash flow.
  3. (Optional) Enable Cloud AI for smarter scanning. Settings → AI Models. You'll need your own API key from one of the supported providers. Setup steps for each are here. Apple Intelligence (on iOS 26+) works without an API key.
  4. Try Demo Mode if you want to explore every feature on sample data without committing real records. Settings → Demo Mode. One tap to switch back.

Frequently asked questions

Does ReceiptMaster work without an internet connection?

Yes — fully. Scanning, OCR, budget tracking, statistics, and notifications all work offline. Network is only used (a) when you opt-in to Cloud AI and trigger one of the three AI features, (b) optionally for iCloud Sync between your own devices, or (c) for the App Store / StoreKit when you purchase the Pro upgrade.

Where is my data stored?

On your device, in iOS's secure SwiftData storage. If you enable iCloud Sync (Settings → iCloud Sync), it also syncs through your own private CloudKit database — counted against your iCloud quota, not ours. We operate no servers and have no access to your data.

My receipt scan picked the wrong amount / merchant — how do I fix it?

Tap any scanned field on the review screen before saving to edit it. The app remembers your corrections on-device to improve future scans of similar receipts.

Apple Intelligence vs. Cloud AI vs. no AI — which should I use?

Apple Intelligence (if your device supports it on iOS 26+) is best — local, free, no API key. If unavailable, Cloud AI with your own API key gives the best accuracy but requires a paid account with the provider. Without either, the app falls back to local regex parsing, which works well for clear paper receipts in supported languages.

What gets sent to the cloud when I enable Cloud AI?

It depends on which feature you trigger. Full disclosure: see the Privacy Policy — every payload is listed line by line. In short: receipt OCR text + your own budget rule names (never the photo), or aggregated budget / cash-flow numbers. We never send your name, email, location, device ID, individual transactions, or merchant names.

How do I get an API key for OpenAI / Claude / Qwen / Doubao / DeepSeek?

See the AI Setup Guide — step-by-step for each provider, including where to sign up and how to paste the key into the app.

Can I export my data?

Yes — Settings → Export to CSV. The exported file contains all your transactions and can be opened in Numbers, Excel, or any spreadsheet app.

How does the Pro subscription work?

One-time purchase via the App Store. It unlocks unlimited budget rules, multi-currency, advanced statistics, and the AI Advisor / AI Budget Review features. Family sharing is supported. The free tier remains fully usable for receipt scanning + basic planning.

The app crashed or behaves strangely — what should I do?

Force-quit (swipe up + flick the app away) and reopen. If it persists, please email us with: your iOS version, device model, app version (Settings → Version), and a brief description of what you were doing. We respond within 1–2 business days.

How do I delete all my data?

Delete the app from your iPhone (long-press the icon → Remove App → Delete App). All locally-stored data is removed with the app. If you enabled iCloud Sync, also go to iOS Settings → [Apple ID] → iCloud → Manage Storage → ReceiptMaster → Delete Data.

Troubleshooting

Scans are inaccurate

  • Ensure good lighting and a flat receipt with no glare.
  • Crop tightly — extra background reduces OCR accuracy.
  • For non-Latin scripts (CJK), make sure your iOS device language settings include the script.
  • Try enabling Apple Intelligence or Cloud AI for harder receipts (e.g., faded thermal paper).

iCloud Sync isn't syncing

  • Check that you're signed into the same Apple ID on both devices.
  • iOS Settings → [Apple ID] → iCloud → Apps Using iCloud → ReceiptMaster must be ON.
  • Ensure you have available iCloud storage.
  • Sync can take 1–2 minutes on first set-up.

Cloud AI returns an error

  • Check that your API key is correct (Settings → AI Models → tap the provider).
  • Verify your provider account has billing set up and quota remaining.
  • Make sure your device has an internet connection.
  • If issues persist, try a different provider — the app supports five.

Notifications aren't appearing

  • iOS Settings → Notifications → ReceiptMaster → make sure "Allow Notifications" is ON.
  • Return-deadline reminders only fire for receipts with a deadline date set.

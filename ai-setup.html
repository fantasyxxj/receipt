AI Setup Guide

How to get an API key for each cloud AI provider supported by ReceiptMaster. Last updated: May 2026.

ReceiptMaster supports six paths for AI receipt extraction and cash-flow analysis:

  • • Apple Intelligence — on-device, zero setup, free, but only works on iPhone 15 Pro+ / Apple Silicon iPad
  • • OpenAI — most capable, most expensive, $5 minimum top-up
  • • Anthropic Claude — strong at reasoning, $5 minimum, often a $5 free credit on signup
  • • Alibaba Qwen (International) — generous free monthly quota, recommended for users outside China
  • • Alibaba Qwen (Mainland China) — needs a Chinese ID + +86 phone
  • • DeepSeek — cheapest paid option, OpenAI-SDK compatible
  • • Doubao (Volcengine / BytePlus) — ByteDance's Doubao models, two separate stacks

If you have Apple Intelligence, use it — there's nothing to configure and it costs nothing. If your device doesn't qualify, the most popular fallbacks for ReceiptMaster users are Qwen International (free quota) and DeepSeek (cheapest).

  • 1️⃣Create an account at platform.openai.com (the ChatGPT login also works, but billing is separate).

  • 3️⃣Verify your phone via SMS — landlines and VoIP fail.

Pitfalls. Phone verification with VoIP / Google Voice numbers is the #1 issue. Keys created without topping up return insufficient_quota errors that look like rate limits. OpenAI does not serve mainland China, Russia, or sanctioned regions.
Troubleshooting.
  • insufficient_quota after creating key → you haven't topped up the $5 minimum. Settings → Billing → add card → top up.
  • Phone verification fails with VoIP / Google Voice → use a real mobile number; +86 mainland-China numbers also fail since OpenAI doesn't serve that region.
  • API returns 401 in production but works locally → keys are project-scoped; double-check you copied the right one.

AI 設定ガイド

ReceiptMaster がサポートする各クラウド AI プロバイダの API キー取得手順。最終更新: 2026 年 5 月。

ReceiptMaster はレシート抽出とキャッシュフロー分析のために 6 種類の AI 経路をサポートします:

  • • Apple Intelligence — オンデバイス、設定不要、無料。iPhone 15 Pro+ / Apple Silicon iPad のみ対応
  • • OpenAI — 最高性能、最高料金、最低 $5 のチャージ
  • • Anthropic Claude — 推論に強い、最低 $5、登録時に $5 の無料クレジットがあることが多い
  • • Alibaba Qwen（国際版） — 月毎の無料枠が豊富、海外ユーザー推奨
  • • Alibaba Qwen（中国本土版） — 中国の身分証 + +86 番号必須
  • • DeepSeek — 最安の有料サービス、OpenAI SDK 互換
  • • Doubao（Volcengine / BytePlus） — ByteDance の Doubao モデル、2 つ別系統

Apple Intelligence が利用可能ならそれを使ってください — 設定も料金も不要です。対応していない場合、ReceiptMaster ユーザーで人気の選択肢は Qwen 国際版（無料枠）と DeepSeek（最安）です。

豆包（火山方舟 / BytePlus ModelArk）

位元組跳動用兩套獨立系統提供同樣的豆包模型，按你所在地選：

火山方舟 Volcengine Ark — 中國本土

控制台
console.volcengine.com/ark
Key 格式
UUID 格式（沒有 sk- 前綴）
最便宜模型
Doubao-1.5-lite-32k — 每百萬 tokens 約 ¥0.3 / ¥0.6
免費額度
每個開通的模型 50 萬 tokens，外加滾動「成長獎勵」活動
必須
+86 手機號 + 中國實名認證
  • 1️⃣用 +86 手機號在 volcengine.com 註冊。
  • 2️⃣完成實名認證。
  • 3️⃣頂欄 大模型 → 火山方舟，捲到 API 接入。
  • 4️⃣API Key 管理 → 創建 API Key，複製。
  • 5️⃣到 模型推理，找到要用的 Doubao 模型（如 Doubao-1.5-pro-32k），點 開通服務。模型不開通就不能用。
  • 6️⃣代碼裡要用接入點 ID（ep-…）——模型名不是 ID。

BytePlus ModelArk — 國際版

控制台
console.byteplus.com
必須
信箱 + 本人驗證（護照可），USD 卡支付
區域
ap-southeast-1（新加坡）
  • 1️⃣到 byteplus.com 註冊（跟 volcengine.com 不互通）。
  • 2️⃣完成本人驗證。
  • 3️⃣選 ap-southeast-1，多數 Doubao/Seed 模型在這裡。
  • 4️⃣ModelArk → API Key Management → Create API Key，複製。
  • 5️⃣到模型清單啟用要用的模型。
易錯點。 BytePlus 和火山方舟是完全獨立帳號——key、計費、可用模型都不互通。火山方舟「建 key + 單獨啟用每個模型 + 用接入點 ID」流程特別容易踩坑——把模型名當 ID 貼進去會 404。
故障排查。
  • 火山方舟模型 404 → 必須先在 模型推理 裡點「開通服務」啟用每個 Doubao 模型，程式碼裡用 ep-… 接入點 ID（不是模型名）。
  • BytePlus 的 key 在火山方舟用不了 → 兩套獨立帳號，key 不互通。按所在地選。
  • 實名認證不過 → 只在火山方舟（國內）需要。海外開發者用 byteplus.com 的 BytePlus。

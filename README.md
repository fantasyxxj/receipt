# ReceiptMaster — Legal

Static GitHub Pages site hosting the privacy policy and pointers to the
EULA for the [ReceiptMaster](https://github.com/fantasyxxj/) iOS app.

Live URL: https://fantasyxxj.github.io/receipt/

## Pages

- `index.html` — landing page, links to privacy + EULA
- `privacy.html` — multi-language privacy policy (EN / JA / zh-Hans / zh-Hant)

## Updating

Edit the HTML directly and push. GitHub Pages picks up the change within
a minute or two. Keep the privacy text in sync with the in-app
`PrivacyPolicyView.swift` strings.
